Debug Console for The Binding of Isaac (Flash) uses the font of External Item Descriptions (EID):
https://github.com/wofsauge/External-Item-Descriptions

# Used from EID
- Bitmap font `resources/font/eid_default*` (built from PixelMplus10)
- The mapping of the Flash game's card values to Rebirth's card ids (EID Flash's `item_data.lua`)
